# MVP 版本测试和启动指南

## 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（Windows）
venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置数据库

1. 复制配置文件：
```bash
copy config\app.ini.example config\app.ini
```

2. 编辑 `config/app.ini`，修改数据库连接信息：
```ini
[Database]
server=localhost,1433
database=PPID_DB
login=sa
password=your_password
```

### 3. 初始化数据库

```bash
# 创建数据库表结构
python scripts/init_database.py

# 创建默认管理员用户
python scripts/create_admin.py
```

默认管理员账户：
- 用户名: `admin`
- 密码: `admin123`

**注意**: 生产环境请立即修改密码！

### 4. 测试系统

```bash
# 测试数据库连接
python scripts/test_connection.py

# 运行 MVP 快速测试
python scripts/test_mvp.py
```

### 5. 启动应用

```bash
python src/main.py
```

## 测试步骤

### 基本功能测试

1. **登录测试**
   - 启动应用
   - 使用默认管理员账户登录
   - 验证登录成功

2. **数据查看测试**
   - 选择不同的表（PPIDRecord, UserTable 等）
   - 验证数据可以正常加载和显示
   - 测试刷新功能

3. **数据导出测试**
   - 选择一个表
   - 点击"导出"按钮
   - 选择导出格式（CSV/Excel/JSON）
   - 验证文件可以正常导出

4. **数据删除测试**
   - 选择一条记录
   - 点击"删除"按钮
   - 确认删除
   - 验证记录被软删除（IsDeleted = 1）

5. **统计信息测试**
   - 点击"报表" -> "统计信息"
   - 验证统计信息可以正常显示

## 常见问题

### 1. 数据库连接失败

**症状**: 启动时提示"数据库连接失败"

**解决方案**:
- 检查 SQL Server 是否运行
- 检查 `config/app.ini` 中的连接信息是否正确
- 检查 SQL Server 是否启用 TCP/IP 协议
- 检查防火墙是否允许端口 1433

### 2. 表不存在错误

**症状**: 运行时提示表不存在

**解决方案**:
```bash
python scripts/init_database.py
```

### 3. 登录失败

**症状**: 无法登录

**解决方案**:
```bash
# 创建默认管理员
python scripts/create_admin.py

# 或手动创建用户（需要数据库访问权限）
```

### 4. 权限错误

**症状**: 执行操作时提示权限不足

**解决方案**:
- 确保使用管理员账户登录
- 检查用户角色设置
