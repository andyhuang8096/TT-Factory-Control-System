## 使用方法

### 1. 初始化系统

```bash
# 初始化数据库表结构
python scripts/init_database.py

# 创建默认管理员
python scripts/create_admin.py
```

### 2. 测试系统

```bash
# 测试数据库连接
python scripts/test_connection.py

# 运行 MVP 快速测试
python scripts/test_mvp.py
```

### 3. 运行应用

```bash
python src/main.py
```

使用默认管理员账户登录：
- 用户名: `admin`
- 密码: `admin123`

## 主要功能演示

### 1. 登录系统
- 启动应用后显示登录对话框
- 输入用户名和密码登录
- 登录成功后显示主窗口

### 2. 查看数据
- 在表选择下拉框中选择表
- 数据自动加载到表格中
- 支持刷新数据（F5）

### 3. 导出数据
- 选择要导出的表
- 点击"导出"按钮
- 选择导出格式（CSV/Excel/JSON）
- 选择保存位置

### 4. 删除数据
- 在表格中选择一条记录
- 点击"删除"按钮
- 确认删除操作
- 数据被软删除（IsDeleted = 1）

### 5. 查看统计
- 点击"报表" -> "统计信息"
- 查看系统综合统计报表
